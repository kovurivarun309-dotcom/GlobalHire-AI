# API
Auth: POST /api/auth/register, POST /api/auth/login.
Countries: GET /api/countries, GET /api/countries/{id}.
Cost: POST /api/cost/calculate.
Compliance: POST /api/compliance/analyze.
Decision: POST /api/decision-support/analyze.
Dashboard: GET /api/dashboard/summary.
ML proxy: POST /api/ml/offer-acceptance, /api/ml/hiring-cost, /api/ml/time-to-hire, /api/ml/retention, /api/ml/compliance.
Reports: POST /api/reports/generate.
Swagger UI is available when backend is running.
